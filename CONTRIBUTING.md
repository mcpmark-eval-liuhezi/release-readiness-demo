# Contributing

Thanks for helping improve this repo. Here's how to submit changes:

1. Open an issue describing the problem or proposal before writing code.
2. Create a branch off `main` named after the change.
3. Keep pull requests small and focused on a single concern.
4. Fill out the pull request template, including how the change was tested.
5. Squash commits before merge so the history stays readable.

Once a maintainer has reviewed and approved the change, it can be merged into `main`.
