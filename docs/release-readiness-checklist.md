# Release Readiness Checklist

Every new service must pass this checklist before launch.

## Checklist

- [ ] Actions workflows inventoried
- [ ] Latest release identified
- [ ] Security advisories reviewed

## Notes

- **Actions workflows inventoried** — enumerate every workflow in `.github/workflows` and record what each one is for (CI, deploy, scheduled jobs).
- **Latest release identified** — look up the most recent release in the repository and confirm it is the version the team expects to ship against.
- **Security advisories reviewed** — check the repository's security advisories on file and confirm any open ones have an owner and a remediation plan.
