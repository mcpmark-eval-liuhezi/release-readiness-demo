# Release Checklist

The three checks we always run before every release:

1. **Status checks** - confirm the release pull request's status checks and mergeability.
2. **Automated review** - request a Copilot code review on the release pull request and review its findings.
3. **Security advisories** - check the repository-level and organization-level security advisory listings and confirm nothing is unresolved.

Record every outcome in the audit-log issue.
