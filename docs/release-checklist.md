# Release Readiness Checklist

## 1. Code review
All changes merged for this release have at least one approving review and no unresolved review threads.

## 2. Automated tests green
CI passes on the release candidate commit with no failed or skipped tests.

## 3. Security scan
Vulnerability, dependency, and secret scanning results are reviewed with no unresolved critical or high alerts.

## 4. Sign-off
The release owner records final approval in docs/signoff-log.md before the release is tagged.
